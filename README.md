# ABYSSAL Game

A deep sea survival game built with HTML5 Canvas, CSS, and JavaScript.

## How to Run

Simply open `index.html` in a modern web browser. The game will load and run automatically.

## Game Features

- Deep sea survival gameplay
- Multiple themed zones with increasing difficulty
- Various creatures to eat and avoid (gain energy by eating enemies)
- Power-ups and special abilities
- Touch and mouse controls
- **Burst ability**: Double-tap/click to unleash a powerful area attack that converts nearby enemies to orbs and damages others (requires 25+ energy)

## Controls

- **Drag/Mouse**: Move your creature
- **Double Tap/Click**: Burst - converts nearby enemies to orbs and damages others (requires 25+ energy)
- **Escape/P**: Pause/Resume game

## Development

To modify the game:

1. **HTML changes** - Edit `index.html`
2. **Styling changes** - Edit `styles.css`
3. **Game logic changes** - Edit `game.js`

The code is well-commented and organized into logical sections for easy navigation.
